# LLM Frameworks — Background Notes

A few notes to guide the research:

## Frameworks to Consider

- **LangChain** — most popular, large ecosystem, can be verbose
- **LlamaIndex** — strong on RAG and document pipelines
- **Haystack** — production-focused, good for search/QA
- **DSPy** — programmatic prompting, less hand-crafted chains
- **CrewAI** — multi-agent, role-based task delegation
- **AutoGen** — Microsoft, multi-agent conversations
- **Google ADK** — Google's agent development kit, tight Gemini integration

## Evaluation Criteria

Focus the comparison on:
- GitHub stars (popularity)
- License (MIT, Apache-2.0, etc.)
- Main use case (RAG, agents, pipelines…)
- Python support (version, maturity)

## Notes

Prefer frameworks with active maintenance (last commit < 3 months).
Exclude deprecated or archived repos.
